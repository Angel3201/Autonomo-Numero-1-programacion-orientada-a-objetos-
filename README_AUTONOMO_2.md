# Autonomo-Numero-2-programacion-orientada-a-objetos

Continuación del Sistema de Gestión de Libros Electrónicos realizado en el Autónomo 1.

## Funcionalidades implementadas

* Menú interactivo.
* Registro de libros electrónicos.
* Visualización del catálogo de libros.
* Búsqueda de libros por título.
* Uso de estructuras (structs) para representar libros.
* Uso de slices para almacenar información.
* Encapsulación mediante atributos privados y métodos públicos.
* Implementación de interfaces.
* Manejo de errores en el ingreso de datos.
* Comentarios explicativos en funcionalidades importantes.
